# Toxicology Evidence Catalogue

A static, searchable overview of toxicology data products and their documented downstream use, supporting a manuscript on the FAIR implementation ecosystem in toxicology.

The current snapshot (27 October 2026) contains **48 data products**, grouped by primary domain, with **85 evidence records** and **162 search-log entries**. Hover over or click an impact cell to inspect its evidence, source links and limitations. Click a product name for metadata.

| Indicator | Documented use |
| --- | --- |
| I1 | Integration into another named data product or model |
| I2 | Reuse of product data in scholarly research |
| I3 | Use in an assessment, criterion, method update or decision |

Evidence is distinguished as direct, partial, search incomplete or not yet searched. Searches and independent review are ongoing. These indicators describe recorded examples of use; they are not impact scores, field-wide usage rates or proof that FAIR implementation caused reuse.
